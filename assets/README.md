# Brand assets

Upload the four brand images to this folder with these exact filenames:

- `node-dark.jpg` — node render, dark background (hero)
- `node-white.jpg` — node render, white background (product section)
- `mi350p.jpg` — red MI350P card render
- `cxl-board.jpg` — blue CXL KV-cache board render

GitHub web UI: Add file → Upload files → in the filename field type `assets/node-dark.jpg` to create the folder automatically.
